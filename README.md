# Public_Transport_Delay_Analysis
Data analysis of public transport delays using python and power BI

**Public Transport Delay Analysis**

Tools: Python | Pandas | Power BI

Project Date: August 2026
**
📌 Project Overview**

Public Transport Delay Analysis is a data analytics project focused on understanding public transport delays, route performance, and operational trends. Python and Pandas are used for data cleaning and exploratory data analysis, while Power BI is used to develop an interactive dashboard for analyzing delays across routes, traffic levels, time periods, event types, weather conditions, and weekdays versus weekends.

**🎯 Project Objectives**

Analyze public transport delay patterns across different routes.
Evaluate route performance and identify delay-prone routes.
Examine the impact of traffic levels and weather conditions on transport delays.
Compare delays across different time periods and event types.
Analyze weekday and weekend transport performance.
Develop an interactive Power BI dashboard to support data-driven operational decisions.

**🛠️ Tools and Technologies**

Python: Data analysis and preprocessing.
Pandas: Data cleaning and manipulation.
Matplotlib / Seaborn: Data visualization (if used).
Power BI: Interactive dashboards, charts, and slicers.

**📊 Key Analysis**

1. Route Performance Analysis

Analyzed delays across transport routes to understand route-level performance and identify routes experiencing higher delays.

2. Traffic Level Analysis

Compared transport delays under different traffic conditions to explore the relationship between traffic levels and delays.

3. Time-Based Delay Analysis

Examined delay patterns across different times of the day to identify periods with increased transport delays.

4. Weather and Event Analysis

Explored transport delays under different weather conditions and event types to understand variations in operational performance.

5. Weekday vs Weekend Analysis

Compared transport delay patterns between weekdays and weekends to identify differences in travel and operational trends.

6. Interactive Power BI Dashboard

Developed an interactive dashboard using charts, KPI cards (if included), and slicers to explore transport performance and analyze delay patterns.

**📈 Key Outcomes**

Identified variations in delay patterns across routes and time periods.
Compared transport performance under different traffic conditions.
Explored the relationship between weather conditions, events, and delays.
Evaluated weekday and weekend transport trends.
Presented key findings through an interactive Power BI dashboard.
